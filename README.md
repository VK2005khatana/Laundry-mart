# 🧺 Laundry Wallah / Laundry Mart Website

## 📌 Project Overview
This project is a simple and clean website created using only HTML.  
It represents a laundry service platform where users can view services, check prices, and book services easily.

---

## 🎯 Objective
The main objective of this project is to understand basic HTML structure and create a functional webpage without using CSS or JavaScript.

---

## 🛠️ Technologies Used
- HTML5

---

## ✨ Features
- 🏠 Welcome Section with introduction
- 📋 List of Laundry Services
- 💰 Price Table for services
- 📝 Booking Form (Name, Email, Phone)
- 📧 Contact Information

---

## 📂 Project Structure

## ▶️ How to Run the Project
1. Download or copy the project folder  
2. Make sure all files are in the same folder  
3. Open index.html in any web browser  
4. Website will run locally
